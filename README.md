# 🏎️ McLaren 720S Landing Page

A modern **luxury-inspired landing page** showcasing the iconic **McLaren 720S Spider**.
This project focuses on **clean UI design, responsive layout, and elegant styling** to highlight the car’s **speed, performance, and premium aesthetics**.

Built using **HTML and CSS**, the page demonstrates how simple web technologies can be used to create visually engaging landing pages.

---

## ✨ Features

* 🏎️ **Hero section** featuring the McLaren 720S
* 📱 **Responsive layout** for desktop, tablet, and mobile
* 🎨 Smooth **hover effects** on navigation and buttons
* 📊 Highlighted **performance statistics**
* 🚀 Clear **call-to-action button**
* ✨ Clean and modern **luxury-inspired UI design**

---

## 🛠️ Technologies Used

| Technology            | Purpose                                  |
| --------------------- | ---------------------------------------- |
| **HTML5**             | Page structure and semantic layout       |
| **CSS3**              | Styling, layout, and visual effects      |
| **Responsive Design** | Adapts layout for different screen sizes |

## ⚙️ How It Works

The landing page is structured into sections designed to highlight the vehicle:

1. **Hero Section**

   * Displays the McLaren 720S with a strong visual focus
   * Includes navigation and a call-to-action button

2. **Performance Highlights**

   * Showcases key performance statistics

3. **Responsive Layout**

   * CSS ensures the layout adapts across multiple screen sizes.
